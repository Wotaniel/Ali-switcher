# AliSwitcher

Мини-аналог Punto Switcher / Caramba Switcher для macOS.
Функционал сознательно минимальный:

- **Двойной Shift** → выделяется **фрагмент, набранный не в той раскладке**
  (не одно слово, а всё, что вы написали «не туда» — с пробелами и знаками
  препинания внутри),
- текст конвертируется в **другую раскладку** (ЙЦУКЕН ↔ QWERTY, только
  русский/английский),
- системная раскладка тоже переключается, чтобы продолжать печатать в правильной.

## Как это работает (механизм Punto/Caramba)

1. **Event tap** (CGEventTap) слушает нажатия клавиш. Два нажатия Shift подряд
   (пауза < 0.25 c, между ними отпуск и ни одной другой клавиши) — «двойной шифт».
2. Приложение **запоминает, что вы напечатали** (буфер набора): каждая клавиша
   переводится в символ текущей раскладки через `UCKeyTranslate`. Буфер
   сбрасывается на кликах мыши, стрелках, Enter/Tab и Cmd-сочетаниях.
3. По двойному Shift определяется **граница фрагмента**: от конца набранного
   влево захватываются буквы, цифры, пробелы и знаки препинания до первой буквы
   **другого алфавита** (кириллица ↔ латиница) или перевода строки. Поэтому фраза
   `b yfgbcfk ytcrjkmrj ckjd …` конвертируется целиком.
4. Набранное стирается **Backspace'ами** и печатается конвертированный текст
   (клавиша-в-клавишу: `й→q`, `ц→w`, …; знаки препинания по клавише: `^`→`:`, …).
   Раскладка переключается (Carbon TIS) заранее, чтобы печать была правильной.
   Только клавиши — работает в любом приложении, включая VS Code и Slack.
5. **Выделенный текст**: двойной Shift копирует выделение (`Cmd+C`), конвертирует
   и вставляет обратно (`Cmd+V`) — буфер обмена сохраняется и восстанавливается.
6. Если конвертировать нечего — двойной Shift просто переключает раскладку.
   Поля паролей не слушаются и не трогаются.

Accessibility используется только для уточнения фрагмента по реальному тексту
и определения полей паролей — основная функция работает и без него.

## Сборка

```bash
./build.sh
```

Получится `build/AliSwitcher.app` (без иконки в Dock — это фоновый процесс).

> **Тулчейн:** на этой машине системная Command Line Tools рассинхронизирована
> (компилятор Swift 6.2.1.4.8 vs SDK 6.2.1.4.7 — «SDK is not supported by the
> compiler»). `build.sh` автоматически использует тулчейн **swiftly**
> (`~/.swiftly`), если он установлен: `brew install swiftly && swiftly init -y`.
> Собирается обычным `swiftc`, без SwiftPM.

## Права

Разрешения выдаются в Системных настройках → Конфиденциальность и безопасность:

1. **Наблюдение за вводом** (Input Monitoring) — **обязательно**. Слежение за
   нажатиями клавиш (двойной Shift, запоминание набранного). Без него приложение
   не работает.
2. **Специальные возможности** (Accessibility) — **желательно** (для бонусов):
   конвертация выделенного текста, защита полей паролей, точный фрагмент по
   реальному тексту поля. Основная функция (конвертация набранного) работает
   и без него.

Приложение подписано **стабильным самоподписанным сертификатом**
(`setup-cert.sh` создаёт его один раз), поэтому права выдаются **один раз и
переживают пересборки**. Пока прав нет — иконка в строке меню приглушена,
приложение само переспрашивает и подхватывает права без перезапуска.

## Запуск

```bash
open build/AliSwitcher.app
```

Приложение фоновое (иконки в Dock нет), индикатор — **«RU» в строке меню**
(там же меню: права, инструкция, «Выйти»). Пока открыт диалог прав,
приложение временно видно в Dock (можно вернуть ему фокус).

Автозапуск: Системные настройки → Основные → Элементы входа → «+» → добавить
`build/AliSwitcher.app` (или инсталлер ставит автозапуск сам).

## Отладка

```bash
build/AliSwitcher.app/Contents/MacOS/AliSwitcher --test     # 232 самопроверки
build/AliSwitcher.app/Contents/MacOS/AliSwitcher --layouts  # список раскладок
build/AliSwitcher.app/Contents/MacOS/AliSwitcher             # запуск из терминала
```

Тесты покрывают: транслитерацию (ЙЦУКЕН↔QWERTY), границы фрагмента (ChunkFinder),
карту клавиш (KeyEvents), edge-cases автоконвертации, единый алгоритм
`findConversionRange` (авто + ручная конвертация).

## Установка (рекомендуемый способ — DMG)

```bash
open dist/AliSwitcher.dmg
```

Откроется окно «AliSwitcher» с иконкой приложения и папкой Applications —
**просто перетащите `AliSwitcher.app` в `Applications`** (обычное копирование,
без pkg-инсталлера). Права выдаются один раз: «Наблюдение за вводом» (обязательно)
и «Специальные возможности» (желательно).

Автозапуск: при первом запуске приложение спросит «Запускать при входе?»,
либо переключите в меню иконки «RU» → «Автозапуск при входе».

## Установка на другой машине (Gatekeeper)

Приложение подписано **самоподписанным** сертификатом, поэтому на других
машинах macOS может отказать в запуске: *«Application can't be opened» /
«Apple cannot check it for malicious software»*.

Обход (один из):

1. **Правый клик → «Открыть»** на `AliSwitcher.app` — macOS покажет диалог
   с кнопкой «Открыть» (повторять каждый раз не нужно).
2. Снять quarantine-атрибут в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/AliSwitcher.app
   ```
3. Разрешить вручную через `spctl`:
   ```bash
   sudo spctl --add --label "AliSwitcher" /Applications/AliSwitcher.app
   ```

Полностью убирает блокировку только подпись **Developer ID** (платная, ~$99/год,
Apple Developer Program) — тогда приложение открывается везде без предупреждений.

## Удаление

Два способа:

- **Из меню приложения**: иконка «RU» → **«Удалить AliSwitcher…»** — предупреждение,
  затем macOS запросит пароль администратора, и `uninstall.sh` всё удалит.
- **Вручную**: `sudo ./uninstall.sh`

Скрипт останавливает приложение, удаляет его из `/Applications`,
отключает автозапуск (LaunchAgent), забывает запись об установке и чистит логи.

## Заметки разработчику (важно!)

Проект лежит в **iCloud Drive** («My code»), и его фоновый сервис (FileProvider)
периодически подмешивает в `build/` мусор:

- файлы `._` (AppleDouble) и xattr'ы (FinderInfo / fileprovider);
- иногда пересоздаёт файлы от **root** (тогда `rm`/`mv` → «Permission denied»).

Из-за этого: подпись `.app` «случайно» падала, инсталлер мог «терять» приложение
при установке. **Уже учтено в скриптах:**

- `build.sh` — сборка и подпись идут в `/tmp` (вне iCloud), готовый `.app`
  копируется в `build/`.
- `make-dmg.sh` — staging в `/tmp`, DMG собирается, затем копируется в
  `dist/`.

**Правила, чтобы не наступить на грабли:**

1. **Не запускайте сборку через `sudo`** (`sudo ./build.sh` и т.п.) — файлы
   станут root-принадлежными, и удалить их сможет только root.
2. Не пытайтесь «лечить» root-файлы вручную — просто пересоберите
   (`./build.sh`), сборка идёт в /tmp и не зависит от мусора в `build/`.
3. Если `build/` замусорен и мешает — `sudo rm -rf build/AliSwitcher.app`
   (это единственная команда, где sudo оправдан).
4. Лучший вариант на будущее — держать проект вне iCloud (например, в
   `~/Developer`), тогда проблема исчезнет полностью.

## Настройка

Константы в `Sources/AliSwitcher/main.swift` (enum `Timing`):

| Константа | Значение | Что регулирует |
|---|---|---|
| `kDoubleShiftInterval` | 0.25 c | максимальная пауза между двумя Shift |
| `Timing.backspaceDelay` | 0.008 c | пауза между Backspace |
| `Timing.typeDelay` | 0.01 c | пауза между нажатиями клавиш |
| `Timing.layoutSwitchDelay` | 0.05 c | пауза после переключения раскладки |
| `Timing.autoConvertDelay` | 0.02 c | пауза перед backspace в авто-конвертации |
| `Timing.clipboardWait` | 0.15 c | ожидание копирования в буфер |
| `Timing.clipboardRestore` | 0.4 c | задержка перед восстановлением буфера |

Правило границы фрагмента — в `Sources/AliSwitcher/ChunkFinder.swift`.
Логика конвертации (авто + ручная) — в `Sources/AliSwitcher/AutoSwitcher.swift` →
`findConversionRange(in:isManual:)`.

## Возможности

- **Двойной Shift** на выделенном тексте → конвертация через буфер (Cmd+C/V)
- **Авто-конвертация** (Punto style): при нажатии пробела/знака препинания
  слово автоматически проверяется и конвертируется (вкл/выкл в меню)
- **Undo**: двойной Shift сразу после авто-конвертации отменяет её
- **Auto-learn**: отмена авто-конвертации добавляет слово в список исключений
  (больше не конвертируется)
- **Два списка слов**: English (Latin) и Russian (Cyrillic), независимы.
  Редактируются через меню иконки «RU»
- **Ретроактивная конвертация**: если до последнего слова были другие
  слова в той же раскладке — все они конвертируются
- **Защита паролей**: secure fields не слушаются и не трогаются
- **Generation token**: асинхронные callback'и проверяют актуальность
  перед изменением состояния (защита от race conditions)

## Ограничения (осознанно)

- Направление определяется по последнему слову; если текст набран правильно,
  двойной Shift всё равно сконвертирует его в другую раскладку (это toggle —
  повторный двойной Shift вернёт обратно, как в Punto).
- Поля, которые не отдают текст через Accessibility, используют буфер набора
  (tracking through keystrokes) — работает в любом приложении.
- Только RU/EN, только стандартные раскладки (US / Russian).
- Однобуквенные слова не тригерят авто-конвертацию (недостаточно сигнала),
  но конвертируются ретроактивно и вручную.
