# AliSwitcher

**v1.1.0** — macOS-переключатель раскладки (RU↔EN). Мини-аналог Punto Switcher / Caramba Switcher.

Конвертирует набранный или выделенный текст из неправильной раскладки в правильную, переключает системную раскладку и продолжает работу. Только клавиатурные события — работает в любом приложении.

## Возможности

### Двойной Shift — конвертация набранного

Двойной Shift (два нажатия подряд, пауза < 0.25 с) конвертирует **фрагмент, набранный не в той раскладке** — не одно слово, а всё, что вы написали «не туда» (с пробелами и знаками препинания внутри). Граница фрагмента — по смене алфавита (кириллица ↔ латиница).

- **Ретроактивная конвертация**: если до последнего слова были другие слова в той же раскладке — все они конвертируются
- **Направление** определяется по последнему слову (по большинству букв)
- **Повторный двойной Shift** возвращает исходный текст (toggle, как в Punto)
- Набранный текст стирается Backspace'ами и печатается конвертированный (клавиша-в-клавишу: `й→q`, `ц→w`, …)
- **Fallback на буфер обмена**: если в конвертированном тексте есть буквы обоих алфавитов (например "@/"), клавиша-в-клавишу не сработает → используется `Cmd+C`/`Cmd+V`

### Двойной Shift на выделенном тексте

Если текст **выделен** — двойной Shift копирует выделение (`Cmd+C`), конвертирует и вставляет обратно (`Cmd+V`). Буфер обмена сохраняется и восстанавливается. **Повторный двойной Shift** отменяет вставку через `Cmd+Z`.

### Авто-конвертация (Punto style)

При включённом режиме «Auto Switch» (меню иконки «RU») — при нажатии пробела или знака препинания последнее слово автоматически проверяется:

1. Слово misspelled в **своём** языке (например, `ghbdtn` — не английское слово)
2. Конвертированное слово **valid** в другом языке (`привет` — корректное русское)
3. → авто-конвертация: backspace + печать правильного слова

**Защита от ложных срабатываний:**
- Встроенные списки частых слов (~100+ на язык): `the`, `is`, `что`, `она` — не трогаются. Включая однобуквенные: `а`, `в`, `и`, `к`, `о`, `с`, `у`, `я` (RU), `I`, `a` (EN)
- URL, email, пути, IP-адреса, CLI-флаги, snake_case — не конвертируются
- Все-uppercase слова (`HTML`, `API`) — не конвертируются

**Ретроактивная авто-конвертация**: если последнее слово конвертируется, предыдущие слова в той же раскладке тоже проверяются — если они misspelled в своём языке, конвертируются всей группой.

### Undo

Двойной Shift **сразу после** авто-конвертации отменяет её: backspace + печать исходного текста. Если после авто-конвертации пользователь напечатал новый текст — undo не срабатывает, конвертируется новый текст.

### Auto-learn исключений

При включённом «Auto-Learn Exceptions» (меню иконки «RU»): отмена авто-конвертации добавляет слово в список исключений. Больше это слово не конвертируется автоматически.

- **Два независимых списка**: English (Latin words) и Russian (Cyrillic words)
- Направление определяется по алфавиту слова, не по флагу
- Списки редактируются через меню: «English Words…» / «Russian Words…»
- Мануальная конвертация (двойной Shift) **никогда не учится** — только undo

### Защита паролей и кода

- **Secure fields** (поля паролей) не слушаются и не трогаются
- URL, email, пути, IP, CLI-флаги (`-rf`, `--verbose`), snake_case (`my_var`) — не конвертируются

## Как это работает

1. **Event tap** (CGEventTap) слушает нажатия клавиш. Два Shift подряд — «двойной шифт».
2. Приложение **запоминает буфер набора**: каждая клавиша переводится через `UCKeyTranslate`. Буфер сбрасывается на кликах мыши, стрелках, Enter/Tab, Cmd-сочетаниях.
3. По двойному Shift определяется **граница фрагмента**: от конца набранного влево захватываются буквы, цифры, пробелы и знаки препинания до первой буквы **другого алфавита** или перевода строки.
4. **Единый алгоритм `findConversionRange`** (в `AutoSwitcher.swift`) определяет, какие слова конвертировать:
   - Последнее слово всегда конвертируется
   - Предыдущие — если тот же алфавит + misspelled в своём языке
   - Для авто: встроенные слова, исключения, проверка конвертированного
   - Для ручной: никаких словарных проверок — пользователь явно попросил
5. Набранное стирается **Backspace'ами** и печатается конвертированный текст. Раскладка переключается (Carbon TIS) заранее.
6. Если конвертировать нечего — двойной Shift просто переключает раскладку.
7. **Safety timeout**: если замена затянулась > 3 секунд — принудительный сброс (защита от зависания клавиатуры).
8. **Generation token**: асинхронные callback'и проверяют актуальность перед изменением состояния — защита от race conditions.

## Сборка

```bash
./build.sh                                    # → build/AliSwitcher.app
build/AliSwitcher.app/Contents/MacOS/AliSwitcher --test  # 232 самопроверки
ditto build/AliSwitcher.app /Applications/AliSwitcher.app # Установка
./make-dmg.sh                                 # → dist/AliSwitcher-1.1.0.dmg
```

Универсальный бинарник (arm64 + x86_64), собирается через `swiftc` (без SwiftPM). На машине с рассинхроном Command Line Tools `build.sh` автоматически использует тулчейн `swiftly` (`~/.swiftely`).

## Права

Разрешения выдаются в Системных настройках → Конфиденциальность и безопасность:

1. **Наблюдение за вводом** (Input Monitoring) — **обязательно**. Двойной Shift, буфер набора. Без него приложение не работает.
2. **Специальные возможности** (Accessibility) — **желательно**. Конвертация выделенного текста, защита полей паролей, точный фрагмент по реальному тексту поля. Основная функция работает и без него.

Приложение подписано стабильным самоподписанным сертификатом (`setup-cert.sh`), поэтому права выдаются **один раз и переживают пересборки**. Пока прав нет — иконка приглушена, приложение само переспрашивает и подхватывает права без перезапуска.

## Установка

### Из DMG (рекомендуемый)

```bash
open dist/AliSwitcher-1.1.0.dmg
```

Перетащите `AliSwitcher.app` в `Applications`. При первом запуске приложение спросит «Запускать при входе?».

### На другой машине (Gatekeeper)

Приложение подписано самоподписанным сертификатом, поэтому macOS может отказать в запуске. Обход:

```bash
xattr -dr com.apple.quarantine /Applications/AliSwitcher.app
```

Или: правый клик → «Открыть». Полностью убирает блокировку только подпись Developer ID (~$99/год).

## Удаление

- **Из меню**: иконка «RU» → «Uninstall AliSwitcher…» → пароль → `uninstall.sh` всё удалит
- **Вручную**: `sudo ./uninstall.sh`

## Настройка

Константы в `Sources/AliSwitcher/main.swift` (enum `Timing`):

| Константа | Значение | Что регулирует |
|---|---|---|
| `kDoubleShiftInterval` | 0.25 с | Максимальная пауза между двумя Shift |
| `Timing.backspaceDelay` | 0.008 с | Пауза между Backspace |
| `Timing.typeDelay` | 0.01 с | Пауза между нажатиями клавиш |
| `Timing.layoutSwitchDelay` | 0.05 с | Пауза после переключения раскладки |
| `Timing.autoConvertDelay` | 0.02 с | Пауза перед backspace в авто-конвертации |
| `Timing.clipboardWait` | 0.15 с | Ожидание копирования в буфер |
| `Timing.clipboardRestore` | 0.4 с | Задержка перед восстановлением буфера |

## Ограничения (осознанно)

- Направление определяется по последнему слову. Если текст набран правильно, двойной Shift всё равно сконвертирует его (toggle — повторный вернёт обратно).
- Только RU/EN, только стандартные раскладки (US / Russian).
- Однобуквенные слова конвертируются (в т.ч. автоматически), но встроенные списки (`а`, `в`, `и`, `I`, `a`) защищают частые слова. Нечастые одиночные символы (`ф→a`, `й→q`) тоже конвертируются — почти наверняка чужой раскладкой.
- Поля без Accessibility используют буфер набора (tracking through keystrokes) — работает везде, но без точного текста.
- Это **layout switcher**, не текстовый процессор: нет автозамены `е→ё`, em-dashes, smart quotes.

## Заметки разработчику

Проект лежит в iCloud Drive → FileProvider может мусорить в `build/`. Сборка идёт в `/tmp` (вне iCloud), готовый `.app` копируется в `build/`. DMG собирается в `/tmp`, копируется в `dist/`.

**Не запускайте сборку через `sudo`** — файлы станут root-принадлежными. Если `build/` замусорен: `sudo rm -rf build/AliSwitcher.app` (единственная команда, где sudo оправдан).
